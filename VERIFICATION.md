# Результат проверки практической работы

Дата: 30 октября 2026 года. Все шесть заданий реализованы. Результаты сквозных проверок PostgreSQL и MongoDB подтверждены по сохранённым журналам и JSON-статусам.

## Проверки

| Проверка | PostgreSQL | MongoDB |
|---|---|---|
| Подключение настоящего Node.js-драйвера | Успешно, pg 8.20.0 | Успешно, mongodb 7.7.0 |
| Структура students | Таблица, первичный ключ, NOT NULL, UNIQUE, CHECK | Коллекция, JSON Schema, уникальный индекс email |
| Примеры студентов | Три записи в рабочей базе | Три документа в рабочей базе |
| Общий набор тестов | 56 успешно, 0 ошибок, 0 пропусков | 56 успешно, 0 ошибок, 0 пропусков |
| Настоящий HTTP на порту 3000 | Все шесть маршрутов проверены | Все шесть маршрутов проверены |
| Итоговый статус | passed | passed |

Общий набор из 56 тестов включает проверки с тестовым хранилищем и с настоящей выбранной БД. Это один и тот же набор, выполненный отдельно для каждого хранилища, а не 112 разных сценариев.

В сетевой проверке выполнялись POST → 201, GET списка → 200, GET одного студента → 200, PATCH → 200, PUT → 200, DELETE → 204 и GET удалённой записи → 404. Middleware записывал дату, метод, URL, HTTP-статус и время обработки. Проверочные записи создавались в отдельной базе student_api_test и удалялись. Проверочный HTTP-сервер останавливался после теста.

Для MongoDB дополнительно проверено отклонение документа без обязательного поля (код 121) и повторного email (код 11000) непосредственно на уровне СУБД.

- PostgreSQL: версия 16.13 Homebrew, порт 5432, пользователь eldar. В pgAdmin регистрация называется «PostgreSQL 18», однако запрос version() подтвердил фактическую версию 16.13. Проверка выполнена на Node.js 25.6.1, начало — 2026-10-30T10:32:16.723Z.
- MongoDB: Community 8.0.34, arm64, порт 27017. Установка и запуск службы завершены успешно. Проверка выполнена на Node.js 26.13.0, начало — 2026-10-30T10:50:47.248Z. Homebrew обновил Node.js при установке зависимостей mongosh; PostgreSQL проверялся до этого обновления.

- Команды со сквозными проверками запускались пользователем в обычном Терминале, поскольку командный сеанс агента ограничивает сетевой доступ. Агент прочитал сохранённые результаты и подтвердил успешные статусы и вывод тестов.

## Запуск на этом Mac

Основной режим в локальном .env — PostgreSQL. Для запуска рабочего API выполните npm start в папке /Users/eldar/student-api. Для выбора MongoDB установите DB_DRIVER=mongodb и перезапустите приложение. Базы уже подготовлены.

Локальная служба MongoDB продолжает работать после проверки. Остановить её можно через brew services stop mongodb-community@8.0. HTTP-сервер API после проверки не оставлен работающим.

В ZIP включены код, package-lock.json, инструкция, сравнение СУБД, ответы на контрольные вопросы и подтверждающие журналы. Локальный .env с паролем и каталог node_modules исключены.
